# الجزء الثاني (ملحق): هيكلية مساحة العمل وتوزيع الشاشات حسب الصلاحيات (SIS Workspace Architecture & Role-Based Screens)

تعتمد منصة **"آفاق مدرستي" (Afaq Madrasti SIS)** على معمارية فصل الصلاحيات والأدوار (RBAC) لتوفير مساحة عمل مخصصة وآمنة لكل مستخدم داخل المنظومة التعليمية، متوافقة مع البنية التنظيمية لـ `afaq-school-profile`.

---

## 1. مصفوفة الصلاحيات العامة (RBAC Matrix)

| الدور | الكود البرمجي | النطاق (Scope) | الصلاحيات الأساسية |
|---|---|---|---|
| **مدير المدرسة** | `school_admin` | مدرسة واحدة أو عدة مدارس (`School.manager`) | إدارة المدرسة، الشعب، المعلمين، الطلاب، الحضور، الإعلانات الطارئة، التذاكر |
| **المعلم** | `teacher` | الشعب والمواد المسندة إليه (`TeacherAssignment`) | تسجيل الحضور، نشر الواجبات/المرفقات، الرد على تذاكر أولياء الأمور |
| **ولي الأمر** | `parent` | أبناؤه المرتبطون (`FamilyLink`) | متابعة حضور الأبناء، التقارير الأسبوعية، الإعلانات، فتح تذاكر استفسار |
| **الطالب** | `student` | شعبته الصفية المسجل فيها (`StudentEnrollment`) | الاطلاع على الجدول، الواجبات، الإعلانات، وحالة الحضور الشخصي |
| **مشرف النظام** | `admin` / `developer` | كافة المدارس والمنصة (`IsUsersAdmin` / `IsSystemAdmin`) | إدارة جميع المدارس عبر لوحة الإدارة (`/admin/schools`)، استيراد بيانات المدارس الرسمية، تعيين مديري المدارس |

---

## 2. توزيع الشاشات ووظيفة كل شاشة في مساحة العمل (`/school` و `/school-followup`)

### أ. لوحة تحكم مدير المدرسة (`school_admin Workspace`)
1. **شاشة نظرة عامة والمؤشرات (`/school`)**:
   - **الوظيفة**: عرض إحصائيات المدرسة الفورية (إجمالي الطلاب، عدد المعلمين، الشعب الصفية النشطة، نسبة الحضور الكلية)، ومؤشر ساعات الذروة والطلبات المعلقة.
2. **شاشة إدارة الشعب والطلاب**:
   - **الوظيفة**: عرض وتوزيع الطلاب على الشعب الصفية، وإدارة سجلات التسجيل (`StudentEnrollment`).
   - **أدوات**: استيراد وتصدير الكشوفات جماعياً (Bulk Import/Export via Excel/CSV).
3. **شاشة مراقبة الحضور والغياب الإدارية**:
   - **الوظيفة**: متابعة تقارير الحضور اليومية على مستوى المدرسة والشعب، والتحقق من إرسال إشعارات واتساب الآلية للغياب (`send_whatsapp_alert`).
4. **شاشة الإعلانات والطوارئ**:
   - **الوظيفة**: نشر التعاميم العامة أو الإعلانات الطارئة (`is_emergency=True`) للشعب أو المدرسة، مع تتبع نسب قراءة الإعلانات عبر (`AnnouncementReadReceipt`).
5. **شاشة التذاكر والدعم الإداري**:
   - **الوظيفة**: مراجعة وإدارة التذاكر المفتوحة بين أولياء الأمور والمعلمين والإدارة وإغلاقها.
6. **شاشة إعداد وبناء الجدول الدراسي (Timetable Builder & Scheduling Engine)**:
   - **الوظيفة**: تحديد أوقات الحصص اليومية (`Period`) والاستراحات، بناء الجدول الأسبوعي لكل شعبة عبر شبكة مصفوفة تفاعلية (Matrix Grid Builder) مع منع التعارضات الثلاثية (تعارض المعلم، تعارض الشعبة، تعارض القاعة) في الوقت الفعلي، وتفعيل المجدول الذكي (Smart Auto-Scheduler) للتوزيع الآلي، مع دعم التصدير والطباعة (PDF/Excel).
7. **شاشة السجلات والتكاملات الإدارية (`WhatsApp & EduWave Bulk Import`)**:
   - **الوظيفة**: استيراد كشوفات الطلاب والمعلمين جماعياً بصيغ Excel و CSV المتوافقة مع معايير EduWave، ومراقبة سجلات إرسال إشعارات واتساب الفورية (`WhatsAppNotificationLog`) وحالة التوصيل وإيصالات القراءة.

### ب. لوحة تحكم المعلم (`teacher Workspace`)
1. **شاشة الجدول والشعب (`/school`)**:
   - **الوظيفة**: استعراض الجدول الدراسي الأسبوعي الخاص بالمعلم (حسب إسناداته والقاعات والشعب)، واستعراض الشعب التابعة له.
2. **شاشة الحضور والغياب اليومي**:
   - **الوظيفة**: تسجيل غياب وحضور طلاب الشعبة بضغطة زر لكل حصة أو يوم دراسي، وإطلاق إشعار الغياب الفوري لولي الأمر عبر واتساب.
3. **شاشة الواجبات والمرفقات الصفية**:
   - **الوظيفة**: نشر الإعلانات، الواجبات، والمرفقات التعليمية للشعبة الصفية، ومراجعة مرفقات وتسليمات الطلاب وإدارتها (`Attachment`).
4. **شاشة تذاكر أولياء الأمور**:
   - **الوظيفة**: الرد على استفسارات وتذاكر أولياء الأمور الخاصة بطلابه وتقديم التوجيه الأكاديمي.

### ج. لوحة تحكم ولي الأمر (`parent Workspace`)
1. **شاشة بوابة العائلة (الأبناء المرتبطين)**:
   - **الوظيفة**: التبديل السريع بين حسابات الأبناء المسجلين في النظام عبر روابط العائلة (`FamilyLink`) واستعراض الجدول الدراسي الأسبوعي وحالة اليوم لكل ابن.
2. **شاشة الحضور والغياب للأبناء**:
   - **الوظيفة**: عرض سجل الحضور والغياب اليومي والتاريخي لكل ابن مع تنبيهات واتساب الفورية عند الغياب.
3. **شاشة الواجبات والإعلانات**:
   - **الوظيفة**: متابعة الإعلانات المدرسية والواجبات الصفية وتأكيد قراءتها.
4. **شاشة التقارير الأسبوعية (`WeeklyReport`)**:
   - **الوظيفة**: استعراض الملخص الأسبوعي لمستوى وسلوك وحضور الابن.
5. **شاشة تذاكر الاستفسارات (`ParentTeacherTicket`)**:
   - **الوظيفة**: فتح تذكرة جديدة مع معلم المادة أو الإدارة الدراسية لمتابعة حالة الطالب واستفساراته.

### د. لوحة تحكم الطالب (`student Workspace`)
1. **شاشة الملخص الدراسي**:
   - **الوظيفة**: ملخص اليوم الدراسي، الجدول، التنبيهات، والواجبات المطلوبة.
2. **شاشة الواجبات والإعلانات الصفية**:
   - **الوظيفة**: الاطلاع على الإعلانات والواجبات والمرفقات الدراسية للشعبة.
3. **سجل الحضور الشخصي**:
   - **الوظيفة**: متابعة نسبة الحضور والغياب الخاصة به.

## 3. التكامل مع المساعد الذكي والصوت (`AI & Voice Integration`)
* **إعدادات المستخدم الذكية (`UserAISetting`)**: السماح للمعلمين وأولياء الأمور بتخصيص نبرة المساعد الذكي وسرعة الصوت ومستوى التعقيد.
* **التحويل الصوتي (`voice/transcribe` & `voice/synthesize`)**: دعم إملاء الملاحظات والإعلانات صوتياً وتحويل النصوص إلى صوت داخل مساحة العمل المدرسية.

---

## 4. تكامل نظام التنبيهات الفورية عبر مساحات العمل المدرسية (`Toast Notifications Integration`)

تم ربط نظام التنبيهات الفورية (`useToast`) بشكل كامل عبر مختلف المكونات والشاشات الإدارية ومساحات العمل لتوفير استجابة بصرية فورية ودقيقة للمستخدمين:

1. **مساحة عمل مدير المدرسة (`School Admin / AdminRoomsView` وغيرها)**:
   - **الاستخدام**: إظهار تنبيهات نجاح أو خطأ فورية عند تحديث نمط تخصيص القاعات (`room_allocation_mode`)، إعداد القاعات الثابتة، حفظ وتعديل جداول الحصص الدراسية، وإدارة بيانات الشعب والطلاب.
   - **مثال**: `success(t("bannerRoomModeUpdated"))` أو `error(t("bannerRoomModeError"))`.

2. **مساحة عمل المعلم (`TeacherWorkspace`)**:
   - **الاستخدام**: تأكيد تسجيل الحضور والغياب اليومي للطلاب، نشر الواجبات والمرفقات، وإرسال التعاميم الصفية مع استجابة بصرية فورية عبر `useToast()`.

3. **مساحة عمل ولي الأمر (`ParentWorkspace`)**:
   - **الاستخدام**: إشعارات فورية عند إرسال تذاكر الاستفسارات (`ParentTeacherTicket`)، تأكيد قراءة الإعلانات المدرسية، ومتابعة تحديثات الحضور.

4. **مساحة عمل الطالب (`StudentWorkspace`)**:
   - **الاستخدام**: تنبيهات تفاعلية عند تسليم الواجبات، استلام الإعلانات العامة، وتحديثات الجدول الدراسي الشخصي.
