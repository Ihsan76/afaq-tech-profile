# معجم المصطلحات (Glossary)

## مصطلحات تقنية عامة

| المصطلح | الاختصار | التعريف بالعربية | التعريف بالإنجليزية |
|---------|----------|-----------------|---------------------|
| **AI** | — | الذكاء الاصطناعي | Artificial Intelligence |
| **API** | — | واجهة برمجة التطبيقات | Application Programming Interface |
| **Backend** | — | الخلفية — الجزء الذي يعمل على الخادم | Server-side application |
| **CDN** | — | شبكة توصيل المحتوى | Content Delivery Network |
| **CRUD** | — | إنشاء، قراءة، تعديل، حذف | Create, Read, Update, Delete |
| **CORS** | — | مشاركة الموارد عبر الأصل | Cross-Origin Resource Sharing |
| **CSRF** | — | تزوير الطلبات عبر المواقع | Cross-Site Request Forgery |
| **Docker** | — | أداة لتشغيل التطبيقات في حاويات | Container platform |
| **E2E** | — | اختبار من النهاية إلى النهاية | End-to-End testing |
| **Frontend** | — | الواجهة الأمامية — الجزء الذي يراه المستخدم | Client-side application |
| **JWT** | — | رمز مصادقة رقمي | JSON Web Token |
| **OAuth** | — | بروتوكول تفويض للمصادقة | Open Authorization |
| **ORM** | — | طبقة تحويل الكائنات لقاعدة البيانات | Object-Relational Mapping |
| **REST** | — | بنية واجهات برمجة التطبيقات المعمارية | Representational State Transfer |
| **SSR** | — | عرض من جانب الخادم | Server-Side Rendering |
| **ISR** | — | إعادة توليد الساكن تدريجياً | Incremental Static Regeneration |
| **PWA** | — | تطبيق ويب تقدمي | Progressive Web App |
| **WAF** | — | جدار حماية تطبيقات الويب | Web Application Firewall |
| **SSL/TLS** | — | بروتوكول أمان الاتصال | Secure Sockets Layer / Transport Layer Security |
