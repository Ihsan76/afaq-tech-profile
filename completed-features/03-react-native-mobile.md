# خطة هندسة تطبيق الموبايل (React Native / Expo)

> تاريخ التوثيق: 17 أغسطس 2026
> الغرض: توثيق التصميم الهندسي والمعماري لتطوير تطبيق الهاتف المحمول عبر React Native و Expo لمنصة آفاق تكنولوجي.

---

## 1. الفكرة والهدف
توفير تطبيق موبايل أصلي (iOS & Android) لأولياء الأمور، المعلمين، والطلاب لتسهيل متابعة الواجبات، الحضور والغياب، وجداول الحصص، واستلام الإشعارات الفورية (Push Notifications) على مدار الساعة.

---

## 2. المكونات التقنية
- **إطار العمل:** React Native مع **Expo** لضمان سرعة التطوير والنشر المشترك على المنصات.
- **التواصل مع السيرفر:** استخدام نفس واجهات الـ REST APIs و JWT Authentication الموجودة في الخلفية (`/api/v1/`).
- **إدارة الحالة:** Zustand وتخزين آمن عبر `Expo SecureStore` لحفظ التوكنز.
- **الإشعارات الفورية:** دمج خدمة Firebase Cloud Messaging (FCM) وتكاملها مع نظام الإشعارات في الخلفية (`apps.notifications` أو `pywebpush`).
