## نظرة عامة

**آفاق تكنولوجي** (Afaq Technology) هي منصة رقمية شاملة تجمع بين التعليم، الأدوات الذكية، الخدمات الرقمية، والذكاء الاصطناعي تحت مظلة واحدة. تأسست المنصة على رؤية تحول التعليم التقليدي إلى تجربة رقمية تفاعلية تدعم المعلمين والطلاب وصناع المحتوى التعليمي بأدوات ذكية متطورة.

---

## الرؤية

> أن نكون المنصة الرقمية الرائدة في المنطقة العربية التي تجمع التعلم والأدوات والخدمات في مكان واحد، مع التركيز على دعم اللغة العربية بشكل معماري سليم كأولوية أساسية.

---

## القيمة المضافة

| المستخدم | القيمة |
|----------|--------|
| **المعلم** | أدوات ذكية لإعداد خطط الدروس وتوفير وقت التحضير |
| **الطالب** | تجربة تعليمية تفاعلية مع تتبع التقدم والمساعد الذكي |
| **صانع المحتوى** | منصة لإنشاء وإدارة وبيع المحتوى التعليمي |
| **الإدارة** | لوحة تحكم شاملة مع تقارير وإحصائيات |
| **العملاء الخارجيون** | حلول رقمية متكاملة وخدمات مؤسسية |

---

## المنتجات الأساسية

1. **منصة خطط الدروس بالذكاء الاصطناعي** — مولد خطط درس ذكي للمعلمين
2. **الأكاديمية التعليمية الشاملة** — كورسات ومسارات تعليمية متعددة
3. **لوحة الطلاب** — تتبع التقدم والمساعد الذكي
4. **أدوات رقمية متنوعة** — خدمات رقمية خارج التعليم
5. **خدمات مؤسسية (B2B)** — حلول رقمية مخصصة للشركات والمؤسسات
6. **نظام الدفع والاشتراكات** — اشتراكات، محفظة، إحالات، فواتير

- **صفحات هبوط** — صفحات تسويقية للمنتجات والخدمات

## المبدأ الأساسي: المنصة ديناميكية

> **جميع المنتجات والخدمات في آفاق تكنولوجي ديناميكية** — يمكن إضافتها أو تعديلها أو إيقافها أو حذفها في أي وقت من لوحة تحكم المدير دون الحاجة لتحديث تقني.

### ماذا يعني ذلك عملياً؟

```
┌─────────────────────────────────────────────────────────────────┐
│                  مرونة المنصة الكاملة                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  📦 المنتجات التعليمية:                                         │
│  ├── إضافة مادة دراسية جديدة ← فورية                          │
│  ├── إضافة مرحلة دراسية جديدة ← فورية                         │
│  ├── تحديث المناهج السنوية ← من لوحة التحكم                    │
│  └── إيقاف مادة مؤقتاً ← مع الحفاظ على البيانات              │
│                                                                  │
│  🛠️ الخدمات الرقمية:                                            │
│  ├── إضافة خدمة جديدة (مواقع، تسويق، ...) ← فورية            │
│  ├── تعديل سعر خدمة ← تحديث فوري                              │
│  ├── إيقاف خدمة مؤقتاً ← إخفاء من الواجهة                    │
│  └── حذف خدمة نهائياً ← مع تأكيد                              │
│                                                                  │
│  💰 التسعير:                                                    │
│  ├── تعديل أسعار الاشتراكات                                    │
│  ├── إضافة عروض وخصومات                                        │
│  ├── إنشاء أكواد خصم                                           │
│  └── جدولة تغييرات الأسعار                                     │
│                                                                  │
│  📅 التوقيت:                                                    │
│  ├── تحديد مواعيد توفر الخدمات                                 │
│  ├── عروض لفترة محدودة                                          │
│  ├── موسمية (back to school مثلاً)                             │
│  └── إتاحة تدريجية للخدمات الجديدة                             │
│                                                                  │
│  ⚡ كل هذا يتم من لوحة التحكم بدون تدخل تقني                  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## البنية التقنية

| المكون | التقنية |
|--------|---------|
| الواجهة الأمامية | Next.js 16 (App Router) + TypeScript + Tailwind v4 + next-intl |
| الخلفية | Django 5.x + DRF |
| قاعدة البيانات | PostgreSQL 15+ (Supabase — Transaction Pooler) |
| الذكاء الاصطناعي | Gemini (google-genai)، OpenAI، Ollama — عبر ProviderRouter |
| النشر | Vercel (فرونت) + Render (باكند) + Cloudflare (CDN/WAF) |
| الموبايل | PWA ثم React Native |

> **الحالة (أغسطس 2026)**: المنصة **حية على الإنتاج** — `afaq.app` (Vercel) + `api.afaq.app` (Render) خلف Cloudflare؛ الأداء محسّن (LocMemCache بدل Redis المحجوب، ترجمات مصفّاة ~56KB، بلا N+1)؛ المراقبة عبر cron-job.org + Sentry.

## الأهداف الاستراتيجية

### قصيرة المدى (0-6 أشهر)
- إكمال النواية الأساسية للمنصة
- إطلاق نظام خطط الدروس بالذكاء الاصطناعي
- تأسيس نظام المصادقة وإدارة المستخدمين

### متوسطة المدى (6-12 شهر)
- توسيع المنتجات التعليمية
- إطلاق لوحة الطلاب
- إضافة نظام الدفع

### طويلة المدى (12-24 شهر)
- التوسع في الخدمات المؤسسية (B2B)
- بناء نظام الزرعاء
- التوسع الجغرافي
