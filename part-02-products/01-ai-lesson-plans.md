# منصة خطط الدروس بالذكاء الاصطناعي

## نظرة عامة

**الاسم:** AI Lesson Plans
**الحالة:** قيد التطوير النشط
**الأولوية:** P0 (أساسي)
**المستخدمون المستهدفون:** المعلمون

---

## الوصف

نظام ذكي لإنشاء خطط الدروس للمعلمين باستخدام الذكاء الاصطناعي. يتيح للمعلم إدخال الموضوع والصف والمنهج، ثم يُولّد خطة درس كاملة في ثوانٍ معدودة.

---

## الميزات الرئيسية

### الأساسية (v1)

| الميزة | الوصف |
|--------|-------|
| **إدخال المعاملات** | اختيار المنهج، الصف، المادة، الموضوع، المدة، أسلوب التدريس |
| **توليد ذكي** | استدعاء AI لتوليد خطة درس كاملة |
| **أقسام الخطة** | أهداف، مواد، تهيئة، أنشطة، تقييم، واجب |
| **تعديل يدوي** | تعديل أي قسم بعد التوليد |
| **حفظ واسترجاع** | حفظ الخطط واسترجاعها لاحقاً |
| **تصدير** | PDF، Word، نص عادي، طباعة |
| **تعدد اللغات** | إدخال ومخرجات بلغات متعددة |

### الإضافية (v2) — معظمها مُنفّذ ✅

| الميزة | الوصف | الحالة |
|--------|-------|--------|
| **إعادة التوليد** | إعادة توليد الخطة بأسلوب مختلف | ⏳ غير منفّذ |
| **قوالب مخصصة** | حفظ قوالب مفضلة | ⏳ غير منفّذ |
| **مشاركة (Marketplace)** | مشاركة الخطط مع معلمين آخرين | ✅ مُنفّذ |
| **تقييم الجودة** | تقييم الخطة المولّدة | ⏳ غير منفّذ |
| **اقتراحات ذكية (Smart Prompts)** | اقتراح مواضيع وطرق تدريس | ✅ مُنفّذ |
| **تعديل تفاعلي (Refine)** | تعديل الخطة عبر محادثة AI | ✅ مُنفّذ |
| **توليد ورقة عمل (Worksheet)** | إنشاء ورقة عمل تفاعلية | ✅ مُنفّذ |
| **توليد واجب منزلي (Homework)** | إنشاء واجب منزلي منظم | ✅ مُنفّذ |

## التدفق الأساسي

```
1. المعلم يفتح شاشة إنشاء خطة درس
        ↓
2. يختار المنهج → الصف → المادة
        ↓
3. يدخل الموضوع والمدة وأسلوب التدريس
        ↓
4. يحدد لغة الإدخال والمخرجات
        ↓
5. يضغط "توليد الخطة"
        ↓
6. النظام يستدعي AI Service Layer
        ↓
7. AI Service Layer يبني البرومبت ويتواصل مع المزود
        ↓
8. المزود يُرجع استجابة
        ↓
9. النظام يحلل الاستجابة ويحفظ الخطة
        ↓
10. تظهر الخطة للمعلم مع جميع الأقسام
        ↓
11. المعلم يراجع ويعدّل ويحفظ
```

## الحقول الرئيسية

### نموذج الإدخال

| الحقل | النوع | مطلوب | القيمة الافتراضية | ملاحظات |
|-------|-------|-------|-------------------|---------|
| المنهج | select | نعم | - | مرتبط بالمناهج المتاحة |
| الصف | select | نعم | - | يتحدث حسب المنهج |
| المادة | select | نعم | - | مرتبطة بالمنهج |
| موضوع الدرس | text | نعم | - | وصف الموضوع |
| مدة الحصة | number | نعم | 45 | بالدقائق |
| أسلوب التدريس | select | نعم | تفاعلي | تفاعلي/محاضري/اكتشافي/...">
| لغة الإدخال | select | نعم | ar | اللغة المكتوبة بها |
| لغة المخرجات | select | نعم | ar | اللغة المطلوبة للخطة |
| تضمين التقييم | checkbox | لا | true | إضافة قسم التقييم |
| تضمين الواجب | checkbox | لا | true | إضافة قسم الواجب |
| ملاحظات للـ AI | textarea | لا | - | توجيهات إضافية |

### نموذج الإخراج (خطة الدرس)

| القسم | المحتوى |
|-------|---------|
| **العنوان** | عنوان الخطة المولّدة |
| **البيانات** | المادة، الصف، المدة، اللغة |
| **الأهداف** | أهداف الدرس التعليمية |
| **المواد** | المواد والوسائل المطلوبة |
| **التهيئة** | نشاط البداية |
| **الأنشطة** | الأنشطة التعليمية التفصيلية |
| **التقييم** | طرق تقييم التعلم |
| **الواجب** | الواجب المنزلي |

## واجهات البرمجة — مُنفّذة

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/lesson-plans/generate/` | POST | توليد خطة جديدة (مع caching) |

| `/api/v1/lesson-plans/{id}/refine/` | POST | تعديل تفاعلي عبر AI |
| `/api/v1/lesson-plans/{id}/worksheet/` | POST | توليد ورقة عمل |
| `/api/v1/lesson-plans/{id}/homework/` | POST | توليد واجب منزلي |
| `/api/v1/lesson-plans/{id}/toggle-public/` | POST | مشاركة/إلغاء مشاركة |
| `/api/v1/lesson-plans/{id}/clone/` | POST | استنساخ من السوق |
| `/api/v1/lesson-plans/{id}/like/` | POST | إعجاب |
| `/api/v1/lesson-plans/marketplace/` | GET | سوق الخطط العامة |
| `/api/v1/lesson-plans/smart-prompts/` | GET | اقتراحات prompts سريعة |

## مقاييس النجاح

| المقياس | الهدف | طريقة القياس |
|---------|-------|-------------|
| وقت التوليد | < 5 ثوانٍ | مراقبة AIRun.latency_ms |
| معدل النجاح | > 95% | نسبة AIRun بحالة success |
| رضا المستخدم | > 4/5 | تقييم بعد التوليد |
| عدد التوليدات/شهر | 5,000+ | عدد AIRun |
| معدل إعادة التوليد | < 10% | نسبة regenerate إلى generate |
