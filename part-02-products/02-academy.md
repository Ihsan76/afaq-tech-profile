# الأكاديمية التعليمية الشاملة

## نظرة عامة

**الاسم:** Afaq Academy
**الحالة:** مرحلة التخطيط
**الأولوية:** P1 (مهم)
**المستخدمون المست目标ون:** الطلاب، المعلمون، صنّاع المحتوى

---

## الوصف

منصة تعليمية شاملة تدعم كورسات ومسارات تعليمية متعددة. تتيح لإنشاء وإدارة الدورات التعليمية مع تتبع تقدم الطلاب ونظام تقييم متكامل.

---

## الميزات الرئيسية

### لإنشاء المحتوى (لصانعي المحتوى)

| الميزة | الوصف |
|--------|-------|
| **إنشاء دورات** | عنوان، وصف، صورة، سعر، لغة، مستوى |
| **تقسيم الدورات** | وحدات → دروس |
| **أنواع الدروس** | فيديو، نص، اختبار، تكليف |
| **رفع الملفات** | فيديو، صور، مستندات |
| **المسار التعليمي** | ترتيب الدورات في مسار |
| **المعايير** | شروط اجتياز前置 |

### للتعلم (للطلاب)

| الميزة | الوصف |
|--------|-------|
| **تصفح الدورات** | بحث، تصفيه، تفاصيل |
| **التسجيل** | التسجيل في الدورات |
| **مشاهدة المحتوى** | مشغل فيديو + نص + تفاعل |
| **الاختبارات** | اختبارات تفاعلية فورية |
| **تتبع التقدم** | شريط تقدم + إحصائيات |
| **الشهادات** | شهادة إتمام الدورة |
| **التقييمات** | تقييم الدورة بعد الإتمام |

### للإدارة

| الميزة | الوصف |
|--------|-------|
| **إدارة الدورات** | إضافة/تعديل/حذف |
| **إدارة التسجيلات** | مراجعة وتأكيد التسجيلات |
| **التقارير** | إحصائيات التسجيل والإنجاز |
| **إدارة الأسعار** | تحديد وتعديل الأسعار |

---

## هيكل المحتوى

```
Course (الدورة)
├── Module (الوحدة)
│   ├── Lesson (الدرس) — فيديو
│   ├── Lesson (الدرس) — نص
│   ├── Lesson (الدرس) — اختبار
│   └── Lesson (الدرس) — تكليف
├── Module (الوحدة)
│   └── ...
└── Quiz (اختبار عام)
```

---

## الكيانات المرتبطة

| الكيان | العلاقة | الوصف |
|--------|---------|-------|
| **Course** | أساسي | الدورة التعليمية |
| **Module** | 1:N | الوحداتภายใน الدورة |
| **CourseLesson** | 1:N | الدروس داخل الوحدة |
| **Enrollment** | N:N | تسجيل الطلاب في الدورات |
| **Progress** | 1:N | تقدم الطالب في كل درس |
| **Quiz** | 1:N | الاختبارات |
| **QuizAttempt** | 1:N | محاولات الاختبار |
| **Certificate** | 1:N | شهادات الإتمام |
| **Review** | 1:N | تقييمات الدورة |
| **CourseCategory** | N:1 | تصنيف الدورة |
| **User** | N:1 | المنشئ / الطالب |

## نموذج البيانات (مبدئي)

### Course

| الحقل | النوع | ملاحظات |
|-------|-------|---------|
| title | CharField | عنوان الدورة |
| slug | SlugField | فريد |
| description | TextField | وصف طويل |
| instructor | ForeignKey → User | المنشئ |
| thumbnail | ImageField | الصورة الرئيسية |
| price | DecimalField | السعر (0 = مجاني) |
| is_published | BooleanField | حالة النشر |
| category | ForeignKey → CourseCategory | التصنيف |
| language | CharField | اللغة |
| level | CharField | beginner/intermediate/advanced |
| duration_hours | DecimalField | المدة الإجمالية بالساعات |
| enrollment_count | IntegerField | عدد المسجلين |
| rating | DecimalField | متوسط التقييم |

### Enrollment

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| user | ForeignKey → User | الطالب |
| course | ForeignKey → Course | الدورة |
| status | CharField | active/completed/cancelled |
| progress | DecimalField | نسبة الإنجاز |
| enrolled_at | DateTimeField | تاريخ التسجيل |
| completed_at | DateTimeField | تاريخ الإتمام |

## واجهات البرمجة المطلوبة

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/courses/` | GET | قائمة الدورات |
| `/api/v1/courses/{slug}/` | GET | تفاصيل الدورة |
| `/api/v1/courses/` | POST | إنشاء دورة (منشئ المحتوى) |
| `/api/v1/courses/{id}/enroll/` | POST | التسجيل في الدورة |
| `/api/v1/courses/{id}/progress/` | GET | تتبع التقدم |
| `/api/v1/courses/{id}/lessons/{id}/` | GET | عرض الدرس |
| `/api/v1/courses/{id}/quiz/` | GET | عرض الاختبار |
| `/api/v1/courses/{id}/certificate/` | GET | تحميل الشهادة |
