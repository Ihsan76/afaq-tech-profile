# لوحة الطلاب

## نظرة عامة

**الاسم:** Student Dashboard
**الحالة:** مرحلة التخطيط
**الأولوية:** P1 (مهم)
**المستخدمون المست目标ون:** الطلاب

---

## الوصف

لوحة تحكم مخصصة للطلاب توفر أدوات تتبع التقدم والمساعد الذكي والتصفح السهل للمحتوى التعليمي.

---

## الميزات الرئيسية

### الأساسية

| الميزة | الوصف |
|--------|-------|
| **لوحة التحكم** | نظرة عامة على التقدم والأنشطة |
| **الدورات المسجلة** | قائمة الدورات المسجل فيها |
| **تتبع التقدم** | شريط تقدم لكل دورة |
| **المساعد الذكي** | دردشة تفاعلية للإجابة على الأسئلة |
| **الاختبارات** | اختبارات تفاعلية وتقييم ذاتي |
| **الإشعارات** | إشعارات بالتحديثات والمواعيد |

### الإضافية

| الميزة | الوصف |
|--------|-------|
| **جدول دراسي** | جدول مخصص للمواعيد |
| **المفضلة** | حفظ الدورات والمحتوى المفضل |
| **الإنجازات** | شارات وإنجازات للتحفيز |
| **السيرة الذاتية التعليمية** | ملخص الإنجازات والشهادات |
| **وضع offline** | تحميل للمشاهدة بدون إنترنت |

## الكيانات المرتبطة

| الكيان | العلاقة | الوصف |
|--------|---------|-------|
| **User** | أساسي | الطالب |
| **Enrollment** | 1:N | التسجيلات في الدورات |
| **Progress** | 1:N | تقدم الطالب في كل درس |
| **QuizAttempt** | 1:N | محاولات الاختبار |
| **Certificate** | 1:N | الشهادات المحصّلة |
| **ChatMessage** | 1:N | رسائل المساعد الذكي |
| **Bookmark** | 1:N | المحتوى المفضل |

## المساعد الذكي — التفاصيل التقنية

### نموذج العمل

1. الطالب يرسل سؤال
2. النظام يجمع السياق (المادة، الدورة، الدرس الحالي)
3. النظام يبني برومبت يحتوي على السؤال + السياق
4. النظام يستدعي AI provider المناسب
5. الاستجابة تُعرض للطالب
6. المحادثة تُحفظ للمراجعة لاحقاً

### السياق المُرسل للـ AI

```json
{
  "student_level": "secondary",
  "subject": "physics",
  "course": "فيزياء 2",
  "current_lesson": "الحركة الدورانية",
  "question": "ما الفرق بين القوة والوزن؟",
  "language": "ar"
}
```

### القيود

- لا يُسمح بإجابات حول محتوى غير تعليمي
- الإجابات تقتصر على المادة الدراسية
- ربط بالإجابات بالمحتوى الموجود في الدورة
- تنبيه للمعلم إذا كان السؤال خارج النطاق
