# أدوات رقمية متنوعة

## نظرة عامة

**الاسم:** Digital Tools
**الحالة:** مرحلة التفكير المبدئي
**الأولوية:** P2 (متوسط)
**المستخدمون المست目标ون:** المعلمون، صنّاع المحتوى

---

## الوصف

مجموعة أدوات رقمية خارج نطاق التعليم المباشر، تدعم المعلمين وصناع المحتوى في أعمالهم اليومية.

---

## الأدوات المقترحة

| الأداة | الوصف | الأولوية |

## نموذج البيانات (مبدئي)

### Tool

| الحقل | النوع | ملاحظات |
|-------|-------|---------|
| name | CharField | اسم الأداة |
| slug | SlugField | فريد |
| description | TextField | وصف الأداة |
| category | CharField | تصنيف الأداة |
| is_active | BooleanField | هل الأداة متاحة |
| is_free | BooleanField | هل الأداة مجانية |
| usage_count | IntegerField | عدد مرات الاستخدام |
| icon | CharField | أيقونة الأداة |

### ToolUsage

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| user | ForeignKey → User | المستخدم |
| tool | ForeignKey → Tool | الأداة |
| input_data | JSONField | بيانات الإدخال |
| output_data | JSONField | بيانات الإخراج |
| created_at | DateTimeField | وقت الاستخدام |

## واجهات البرمجة المطلوبة

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/tools/` | GET | قائمة الأدوات |
| `/api/v1/tools/{slug}/` | GET | تفاصيل الأداة |
| `/api/v1/tools/{slug}/use/` | POST | استخدام الأداة |
| `/api/v1/tools/history/` | GET | سجل الاستخدام |
