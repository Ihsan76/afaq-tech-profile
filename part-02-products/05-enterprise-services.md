# خدمات مؤسسية (B2B)

## نظرة عامة

**الاسم:** Enterprise Services
**الحالة:** مرحلة التخطيط طويلة المدى
**الأولوية:** P3 (مؤجل)
**المستخدمون المست目标ون:** المديرون، المؤسسات التعليمية

---

## الوصف

حلول رقمية مخصصة للمدارس والمؤسسات التعليمية، توفر إدارة شاملة للمعلمين والطلاب والمحتوى مع تقارير متقدمة وتكامل مع الأنظمة الموجودة.

---

## الميزات الرئيسية

### إدارة المؤسسة

| الميزة | الوصف |
|--------|-------|
| **لوحة تحكم المؤسسة** | نظرة عامة على الأداء والإحصائيات |
| **إدارة الفرع** | دعم فروع متعددة |
| **إدارة الفريق** | إضافة معلمين وتعيين صفوف |
| **الصلاحيات** | أدوار وصلاحيات متعددة |
| **السمة white-label** | تخصيص الهوية البصرية |

### إدارة التعليم

| الميزة | الوصف |
|--------|-------|
| **المناهج المخصصة** | ربط مناهج المؤسسة بالمنصة |
| **التخطيط الجماعي** | تخطيط دروس لعدة معلمين |
| **المتابعة الجماعية** | متابعة تقدم الطلاب جماعياً |
| **التقارير المؤسسية** | تقارير شاملة للأداء |

### التقارير والتحليلات

| التقرير | المحتوى |
|---------|---------|
| **تقرير الأداء العام** | إحصائيات شاملة للمؤسسة |
| **تقرير الأداء التعليمي** | أداء المعلمين والطلاب |
| **تقرير الاستخدام** | إحصائيات استخدام المنصة |
| **تقرير الإيرادات** | للخاصة بالاشتراكات |
| **تقرير مخصص** | حسب احتياجات المؤسسة |

### التكامل

| التكامل | الوصف |
|---------|-------|
| **SIS Integration** | ربط بنظام إدارة الطلاب |
| **LMS Integration** | ربط بأنظمة إدارة التعلم |
| **SSO** | تسجيل دخول موحد |
| **API مخصصة** | واجهات برمجة مخصصة |
| **Webhooks** | إشعارات تلقائية |

## الخدمات الرقمية الإضافية (B2B)

بالإضافة لحلول إدارة المؤسسات التعليمية، تقدم **آفاق تكنولوجي** خدمات رقمية وتقنية شاملة للمؤسسات والأفراد:

### قائمة الخدمات
- تصميم صفحات الهبوط
- تصميم المواقع الإلكترونية
- تطوير وإدارة المواقع
- إدارة صفحات التواصل الاجتماعي
- تصميم وإدارة الحملات الإعلانية
- تصميم الهوية البصرية
- إدارة المحتوى
- التسويق بالبريد الإلكتروني
- تحليلات المواقع
- استشارات رقمية

### نموذج التسعير
- **مجاني**: خدمات أساسية لفترة محدودة بعد الإطلاق
- **مدفوع**: باقات شهرية بعد بناء قاعدة المستخدمين

> **للتفاصيل الكاملة**: راجع [الخدمات الرقمية والتقنية](09-digital-services.md)

## المبدأ الأساسي: المنصة ديناميكية

> **جميع المنتجات والخدمات في آفاق تكنولوجي ديناميكية وقابلة للإدارة**

### ماذا يعني ذلك؟

```
┌─────────────────────────────────────────────────────────────────┐
│                    إدارة الخدمات المركزية                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ✅ إضافة خدمة جديدة → فورية دون تحديث الكود                   │
│  ✅ تعديل خدمة موجودة → تغيير الوصف والسعر والميزات           │
│  ✅ إيقاف خدمة مؤقتاً → إخفاء من الواجهة مع الحفاظ على البيانات│
│  ✅ حذف خدمة نهائياً → مع تأكيد من المدير                      │
│  ✅ تعديل الأسعار والباقات → حسب الموسم أو العروض               │
│  ✅ إضافة منتجات تعليمية جديدة → دورات، محتوى، أدوات           │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### إدارة الخدمات من لوحة التحكم

```python
# نموذج خدمة ديناميكي
class Service(models.Model):
    """خدمة قابلة للإدارة dinamically"""
    
    name = models.CharField(max_length=255)
    description = models.TextField()
    category = models.CharField(max_length=50)
    
    # التسعير الديناميكي
    price = models.DecimalField(max_digits=10, decimal_places=2)
    billing_period = models.CharField(max_length=20)  # one_time, monthly, yearly
    
    # الحالة
    is_active = models.BooleanField(default=True)  # تظهر/تختفي
    is_available = models.BooleanField(default=True)  # متاح للطلب
    
    # الترتيب
    order = models.IntegerField(default=0)  # ترتيب العرض
    
    # Metadata
    metadata = models.JSONField(default=dict)  # معلومات إضافية مرنة
    
    # التوقيت
    available_from = models.DateTimeField(null=True)  # متاح من تاريخ
    available_until = models.DateTimeField(null=True)  # متاح حتى تاريخ
    
    class Meta:
        ordering = ['order']
```

### أمثلة على الاستخدام

```
المدير يضيف خدمة جديدة:
1. يذهب للوحة التحكم → الخدمات
2. يضغط "إضافة خدمة جديدة"
3. يملأ البيانات (الاسم، الوصف، السعر)
4. يفعّل الخدمة
5. ✅ الخدمة تظهر فوراً للمستخدمين

المدير يتعديل سعر خدمة:
1. يختار الخدمة من القائمة
2. يعدل السعر
3. يحفظ
4. ✅ السعر يتحدث فوراً

المدير يوقف خدمة مؤقتاً:
1. يختار الخدمة
2. يلغي تفعيل "متاح"
3. يحفظ
4. ✅ الخدمة تختفي من الواجهة لكن البيانات محفوظة
```

### مرونة المنتجات التعليمية

المنهاج الدراسي:

### نموذج التسعير الديناميكي

```python
class PricingPlan(models.Model):
    """باقة تسعير مرنة"""
    
    name = models.CharField(max_length=100)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    currency = models.CharField(max_length=3, default='USD')
    
    # الميزات (JSON مرنة)
    features = models.JSONField(default=list)
    
    # الحدود
    limits = models.JSONField(default=dict)
    
    # التفعيل
    is_active = models.BooleanField(default=True)
    
    # التوقيت
    valid_from = models.DateTimeField(null=True)
    valid_until = models.DateTimeField(null=True)
    
    # العروض
    discount_percent = models.IntegerField(default=0)
    promo_code = models.CharField(max_length=50, blank=True)
```
