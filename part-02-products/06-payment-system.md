# نظام الدفع والاشتراكات

## نظرة عامة

**الاسم:** Payment System
**الحالة:** الاشتراكات منفّذة (أغسطس 2026) — المحفظة/B2B/الإحالة مخططة
**الأولوية:** P2 (متوسط)
**ملاحظة مهمة:** الخدمات الأساسية مجانية في البداية، ثم نتحول للبيع تدريجياً. الاشتراكات (Stripe + MyFatoorah) منفّذة فعلياً.

---

## نموذج الأعمال

### استراتيجية التسعير

#### المرحلة الأولى (مجانية — 6-12 شهر)
- جميع الخدمات الأساسية مجانية
- هدف: بناء قاعدة مستخدمين
- لا حاجة لبوابات دفع في هذه المرحلة

#### المرحلة الثانية (اشتراكات — بعد 12 شهر)
- خطة مجانية محدودة
- خطة احترافية مدفوعة
- خدمات متقدمة مدفوعة

#### المرحلة الثالثة (تجارية — بعد 18 شهر)
- B2B للمؤسسات
- تخصيص المنصة
- دعم فني مخصص

## نظام الإحالة (Affiliate)

### آلية العمل
1. المستخدم يحصل على كود إحالة فريد
2. يشارك الكود مع الأصدقاء
3. عند تسجيل صديق بالكود، يحصل المستخدم على عمولة
4. العمولة تُضاف إلى المحفظة

### نسب العمولة

| الحالة | النسبة |
|--------|--------|
| إحالة ناجحة (تسجيل) | 10% من أول اشتراك |
| تحويل للخطة المدفوعة | 15% من قيمة الاشتراك |

### نموذج البيانات

#### Affiliate

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| user | OneToOne → User | المستخدم |
| code | CharField | كود الإحالة (فريد) |
| commission_rate | DecimalField | نسبة العمولة |
| total_earnings | DecimalField | إجمالي الأرباح |
| is_active | BooleanField | هل الحساب نشط |

#### AffiliateReferral

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| affiliate | ForeignKey → Affiliate | الزرعاء |
| referred_user | ForeignKey → User | المستخدم المُحال |
| commission | DecimalField | العمولة |
| status | CharField | pending/approved/paid |
| created_at | DateTimeField | تاريخ الإحالة |

## بوابات الدفع

### البوابات المدعومة

| البوابة | الدولة | الحالة | الأولوية |
|---------|--------|--------|----------|
| **Stripe** | عالمي | ✅ منفّذ (الطلبات + الاشتراكات) | P2 |
| **MyFatoorah** | الأردن/الخليج | ✅ منفّذ (الطلبات + الاشتراكات) | P2 |
| **PayPal** | عالمي | P2 | مؤجل |
| **叮 (Telcell)** | الأردن | P3 | مؤجل |
| **Fawry** | مصر | P3 | مؤجل |

> **ملاحظة:** Stripe غير متاح للتاجر الأردني (يلزم كيان أمريكي) — MyFatoorah هي البوابة الفعلية للأردن/الخليج. نفس الويب هوك يعالج النوع `order` و`subscription` (Stripe: metadata `kind`؛ MyFatoorah: `UserDefinedField="subscription:<id>"`).

### متطلبات التكامل
- صفحة دفع آمنة (PCI compliant)
- تأكيد الدفع التلقائي
- معالجة الاسترداد
- تقارير المعاملات

## واجهات البرمجة (المنفّذة فعلياً)

### الاشتراكات (`apps/subscriptions`)

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/subscriptions/plans/` | GET | خطط الاشتراك (عام، محلّي بـ `?locale=`) |
| `/api/v1/subscriptions/current/` | GET | الاشتراك الحالي للمستخدم |
| `/api/v1/subscriptions/purchase/` | POST | شراء باقة `{plan_id, locale}` → `checkout_url` |
| `/api/v1/subscriptions/admin/plans/` | GET/POST | إدارة الباقات (مدير) |
| `/api/v1/subscriptions/admin/plans/<pk>/` | GET/PUT/DELETE | تفاصيل باقة (مدير) |

### الطلبات (`apps/marketplace`)

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/marketplace/payments/webhook/stripe/` | POST | ويب هوك Stripe |
| `/api/v1/marketplace/payments/webhook/myfatoorah/` | POST | ويب هوك MyFatoorah (V2 + HMAC) |
| `/api/v1/marketplace/orders/<id>/checkout/` | POST | إعادة دفع لطلب |

### المخططة (محفظة/إحالة/فواتير)

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/payments/wallet/` | GET | المحفظة |
| `/api/v1/payments/wallet/deposit/` | POST | شحن الرصيد |
| `/api/v1/payments/affiliate/` | GET | حساب الزرعاء |
| `/api/v1/payments/invoices/` | GET | الفواتير |
