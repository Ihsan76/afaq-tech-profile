# الخدمات الإضافية: المدونة، المعرض، صفحات الهبوط

---

## 1. المدونة الرقمية

### نظرة عامة
| العنصر | التفاصيل |
|--------|----------|
| **الاسم** | Afaq Blog |
| **الحالة** | مرحلة التخطيط |
| **الأولوية** | P1 (مهم) |
| **المستخدمون** | جميع الزوار والمستخدمين |

### الميزات

#### لإدارة المحتوى (للأدمن)
- إنشاء وتعديل المقالات
- محرر نصي غني (Rich Text Editor)
- رفع الصور والوسائط
- إدارة التصنيفات والوسوم
- جدولة النشر
- مراجعة التعليقات
- SEO management

#### للقراء
- تصفح المقالات بالتصنيفات
- بحث في المقالات
- قراءة المقال مع تنسيق جميل
- التعليق على المقالات
- مشاركة المقالات
- مقالات مشابهة

### أنواع المحتوى

| النوع | الوصف | التكرار |
|-------|-------|---------|
| مقالات تعليمية | نصائح وأدلة للمعلمين والطلاب | أسبوعي |
| أخبار التقنية | آخر التحديثات والأدوات | مرتين أسبوعياً |
| قصص نجاح | تجارب مستخدمين حقيقيين | شهري |
| أدلة عملية | خطوات عملية لاستخدام المنصة | أسبوعي |
| تحليلات | تحليل لاتجاهات التعليم الرقمي | شهري |

### التصنيفات الرئيسية

1. الذكاء الاصطناعي في التعليم
2. أدوات التعليم الرقمي
3. تقنيات الويب
4. تطوير مهارات المعلمين
5. أخبار المنصة
6. قصص نجاح

### نموذج البيانات

#### Post

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| title | CharField | عنوان المقال |
| slug | SlugField | فريد |
| author | ForeignKey → User | الكاتب |
| excerpt | TextField | ملخص مختصر |
| content | TextField | المحتوى (HTML) |
| featured_image | ImageField | الصورة الرئيسية |
| category | ForeignKey → PostCategory | التصنيف |
| tags | ManyToMany → PostTag | الوسوم |
| status | CharField | draft/published/archived |
| published_at | DateTimeField | تاريخ النشر |
| view_count | IntegerField | عدد المشاهدات |
| reading_time | IntegerField | وقت القراءة بالدقائق |

#### PostCategory

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| name | CharField | اسم التصنيف |
| slug | SlugField | فريد |
| description | TextField | الوصف |
| parent | ForeignKey → self | التصنيف الأب |

#### PostTag

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| name | CharField | اسم الوسم |
| slug | SlugField | فريد |

### APIs المطلوبة

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/blog/posts/` | GET | قائمة المقالات |
| `/api/v1/blog/posts/{slug}/` | GET | تفاصيل المقال |
| `/api/v1/blog/categories/` | GET | التصنيفات |
| `/api/v1/blog/posts/` | POST | إنشاء مقال (أدمن) |
| `/api/v1/blog/posts/{id}/` | PATCH | تعديل مقال |
| `/api/v1/blog/posts/{id}/comments/` | GET | التعليقات |
| `/api/v1/blog/posts/{id}/comments/` | POST | إضافة تعليق |

## 2. معرض الخدمات

### نظرة عامة
| العنصر | التفاصيل |
|--------|----------|
| **الاسم** | Afaq Marketplace |
| **الحالة** | مرحلة التخطيط |
| **الأولوية** | P2 (متوسط) |
| **المستخدمون** | مقدمو الخدمات + العملاء |

### الميزات

#### لمقدمي الخدمات
- إنشاء صفحة خدمة
- تحديد السعر والوصف
- رفع أعمال سابقة
- استقبال طلبات
- إدارة الطلبات
- استلام المدفوعات

#### للعملاء
- تصفح الخدمات
- بحث وتصفية
- عرض تفاصيل الخدمة
- طلب الخدمة
- الدفع
- تقييم الخدمة

### نموذج البيانات

#### Service

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| title | CharField | عنوان الخدمة |
| slug | SlugField | فريد |
| provider | ForeignKey → User | مقدم الخدمة |
| description | TextField | الوصف التفصيلي |
| short_description | CharField | وصف مختصر |
| thumbnail | ImageField | الصورة الرئيسية |
| price | DecimalField | السعر |
| price_type | CharField | fixed/hourly/starting_from |
| category | ForeignKey → ServiceCategory | التصنيف |
| is_active | BooleanField | هل نشطة |
| delivery_time_days | IntegerField | مدة التسليم بالأيام |
| rating | DecimalField | متوسط التقييم |
| order_count | IntegerField | عدد الطلبات |

#### ServiceOrder

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| service | ForeignKey → Service | الخدمة |
| buyer | ForeignKey → User | المشتري |
| status | CharField | pending/in_progress/delivered/completed |
| requirements | TextField | متطلبات العميل |
| total_price | DecimalField | السعر الإجمالي |
| delivery_date | DateField | تاريخ التسليم |
| delivered_at | DateTimeField | تاريخ التسليم الفعلي |

### APIs المطلوبة

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/marketplace/services/` | GET | قائمة الخدمات |
| `/api/v1/marketplace/services/{slug}/` | GET | تفاصيل الخدمة |
| `/api/v1/marketplace/services/` | POST | إنشاء خدمة |
| `/api/v1/marketplace/orders/` | POST | طلب خدمة |
| `/api/v1/marketplace/orders/{id}/` | GET | تفاصيل الطلب |
| `/api/v1/marketplace/orders/{id}/review/` | POST | تقييم الخدمة |

## 3. صفحات الهبوط

### نظرة عامة
| العنصر | التفاصيل |
|--------|----------|
| **الاسم** | Landing Pages |
| **الحالة** | مرحلة التخطيط |
| **الأولوية** | P2 (متوسط) |
| **المستخدمون** | الزوار الجدد |

### أنواع صفحات الهبوط

| الصفحة | الهدف | المحتوى |
|--------|-------|---------|
| **صفحة المنتج الرئيسي** | التحويل | Hero + ميزات + كيف تعمل + أسعار + FAQ |
| **صفحة الأسعار** | مقارنة الخطط | مقارنة الميزات + CTA |
| **صفحة عن المنصة** | بناء الثقة | رؤية + فريق + إنجازات |
| **صفحة تواصل معنا** | التواصل | نموذج اتصال + معلومات |
| **صفحات حملات** | حملات محددة | محتوى مخصص لكل حملة |

### عناصر صفحة الهبوط المثالية

```
┌─────────────────────────────────────────┐
│  Hero Section                           │
│  • عنوان رئيسي جذاب                    │
│  • وصف مختصر للقيمة                    │
│  • CTA رئيسي (سجّل مجاناً)             │
│  • صورة/فيديو توضيحي                   │
├─────────────────────────────────────────┤
│  ميزات المنتج                           │
│  • 3-6 ميزات رئيسية مع أيقونات        │
│  • شرح مختصر لكل ميزة                  │
├─────────────────────────────────────────┤
│  كيف تعمل                              │
│  • 3 خطوات بسيطة                       │
│  • رسوم توضيحية                        │
├─────────────────────────────────────────┤
│  شهادات العملاء                         │
│  • صور + أسماء + تقييمات               │
├─────────────────────────────────────────┤
│  الأسئلة الشائعة                        │
│  • 5-8 أسئلة شائعة مع إجابات          │
├─────────────────────────────────────────┤
│  CTA نهائي                             │
│  • تذكير بالقيمة + زر التسجيل         │
├─────────────────────────────────────────┤
│  Footer                                │
│  • روابط + معلومات + وسائل التواصل     │
└─────────────────────────────────────────┘
```

### نموذج البيانات

#### LandingPage

| الحقل | EventType | ملاحظات |
|-------|-----------|---------|
| title | CharField | عنوان الصفحة |
| slug | SlugField | فريد |
| meta_title | CharField | عنوان SEO |
| meta_description | TextField | وصف SEO |
| content | JSONField | محتوى الصفحة (هيكل JSON) |
| is_active | BooleanField | هل نشطة |
| template | CharField | نوع القالب |
| cta_text | CharField | نص زر الدعوة للعمل |
| cta_link | URLField | رابط الزر |
| published_at | DateTimeField | تاريخ النشر |

### APIs المطلوبة

| الوجهة | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/landing/{slug}/` | GET | عرض صفحة الهبوط |
| `/api/v1/landing/` | GET | قائمة الصفحات (أدمن) |
| `/api/v1/landing/` | POST | إنشاء صفحة (أدمن) |
| `/api/v1/landing/{id}/` | PATCH | تعديل صفحة |
