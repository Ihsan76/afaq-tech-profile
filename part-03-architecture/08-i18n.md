# دليل تعدد اللغات الشامل (i18n Architecture)

## نظرة عامة

تعدد اللغات مدمج في بنية المنصة من البداية — ليس كميزة إضافية بل كجزء من الهوية. المنصة تدعم **9+ لغات** مع فصل واضح بين أربعة أنواع من اللغات.

## فصل اللغات الأربعة

### 1. لغة الواجهة (`ui_language`)
- اللغة التي يراها المستخدم في الواجهة
- تحدد اتجاه RTL/LTR
- تحدد الخطوط المستخدمة
- تحدد تنسيق الأرقام والتواريخ

### 2. لغة الإدخال (`input_language`)
- اللغة التي يكتب بها المستخدم
- قد تكون مختلفة عن لغة الواجهة
- مثال: مستخدم يكتب بالإنجليزية لكن واجهته عربية

### 3. لغة المخرجات (`output_language`)
- اللغة التي تُولّد بها المحتوى
- خطط الدروس، ردود المساعد، الاختبارات
- المستخدم يتحكم بلغة المخرجات بشكل مستقل

### 4. بلد/المنهاج (`source_locale`)
- السياق الجغرافي للمحتوى
- يحدد المناهج الدراسية المستخدمة
- مثال: `jo` (الأردن)، `sa` (السعودية)، `eg` (مصر)

## كشف اللغة التلقائي للزوار الجدد

### المبدأ الأساسي
عند أول زيارة للمستخدم (زائر) يتم تحديد اللغة تلقائياً بناءً على:

1. **لغة المتصفح** (`Accept-Language` header)
2. **أقرب لغة مدعومة** من اللغات المتاحة
3. **اللغة الافتراضية** إذا لم تكن اللغة المدعومة

### خوارزمية كشف اللغة

```typescript
// utils/language-detection.ts

import { locales, defaultLocale } from '@/i18n/config';

/**
 * خوارزمية كشف اللغة للزوار الجدد
 * 1. فحص لغة المتصفح
 * 2. البحث عن أقرب لغة مدعومة
 * 3. استخدام اللغة الافتراضية (en) إذا لم تُوجد
 */
export function detectBrowserLanguage(acceptLanguage: string): string {
  // تحليل header Accept-Language
  const browserLanguages = parseAcceptLanguage(acceptLanguage);
  
  // البحث عن أقرب لغة مدعومة
  for (const browserLang of browserLanguages) {
    const detected = findMatchingLocale(browserLang);
    if (detected) return detected;
  }
  
  // اللغة الافتراضية: الإنجليزية للزوار الجدد
  return 'en';
}

/**
 * تحليل Accept-Language header
 * مثال: "ar,en-US;q=0.9,en;q=0.8,fr;q=0.7"
 */
function parseAcceptLanguage(header: string): Array<{ lang: string; quality: number }> {
  if (!header) return [];
  
  return header
    .split(',')
    .map(part => {
      const [lang, q] = part.trim().split(';q=');
      return {
        lang: lang.split('-')[0].toLowerCase(), // ar-EG → ar
        quality: q ? parseFloat(q) : 1.0,
      };
    })
    .sort((a, b) => b.quality - a.quality);
}

/**
 * البحث عن أقرب لغة مدعومة
 */
function findMatchingLocale(browserLang: string): string | null {
  // تطابق مباشر
  if (locales.includes(browserLang as any)) {
    return browserLang;
  }
  
  // تطابق جزئي (مثل: fr-CA → fr)
  const partialMatch = locales.find(loc => 
    browserLang.startsWith(loc) || loc.startsWith(browserLang)
  );
  
  return partialMatch || null;
}
```

### جدول التطابق

| لغة المتصفح | اللغة المكتشفة | ملاحظات |
|-------------|---------------|---------|
| `ar`, `ar-SA`, `ar-EG`, `ar-JO` | `ar` | أي لهجة عربية |
| `en`, `en-US`, `en-GB` | `en` | أي لهجة إنجليزية |
| `fr`, `fr-FR`, `fr-CA` | `fr` | أي لهجة فرنسية |
| `tr`, `tr-TR` | `tr` | تركية |
| `ur`, `ur-PK` | `ur` | أوردو |
| `es`, `es-MX`, `es-ES` | `es` | إسبانية |
| `de`, `de-DE` | `de` | ألمانية |
| `id` | `id` | إندونيسية |
| `bn`, `bn-BD` | `bn` | بنغالية |
| `zh`, `ja`, `ko` | `en` | غير مدعومة → إنجليزية |
| `pt`, `ru`, `it` | `en` | غير مدعومة → إنجليزية |

### تدفق الكشف

```
الزائر الجديد
    ↓
هل له cookie/localStorage بلغة محفوظة؟
    ├── نعم → استخدام اللغة المحفوظة
    └── لا ↓
        ↓
هل المتصفح يرسل Accept-Language؟
    ├── نعم ↓
        ↓
        هل توجد لغة مدعومة في القائمة؟
            ├── نعم → استخدام اللغة المطابقة
            └── لا → استخدام الإنجليزية (en)
        ↓
    └── لا → استخدام الإنجليزية (en)
```

### التخزين

```typescript
// عند اكتشاف اللغة لأول مرة
function saveLanguagePreference(locale: string) {
  // حفظ في localStorage للمتصفح
  localStorage.setItem('afaq-locale', locale);
  
  // حفظ في cookie للـ SSR
  document.cookie = `afaq-locale=${locale}; path=/; max-age=31536000`;
  
  // تحديث اتجاه الصفحة
  document.documentElement.dir = rtlLocales.includes(locale as any) ? 'rtl' : 'ltr';
  document.documentElement.lang = locale;
}

// عند العودة للموقع
function getSavedLanguage(): string | null {
  // فحص localStorage أولاً
  const saved = localStorage.getItem('afaq-locale');
  if (saved) return saved;
  
  // فحص cookie
  const match = document.cookie.match(/afaq-locale=([^;]+)/);
  if (match) return match[1];
  
  return null;
}
```

### مثال عملي

```
المستخدم في الأردن لأول مرة:
├── المتصفح: ar-JO
├── الكشف: ar (مدعومة)
├── النتيجة: واجهة عربية
└── التخزين: ar في localStorage

المستخدم في البرازيل لأول مرة:
├── المتصفح: pt-BR
├── الكشف: pt (غير مدعومة)
├── النتيجة: واجهة إنجليزية (en)
└── التخزين: en في localStorage

المستخدم في فرنسا لأول مرة:
├── المتصفح: fr-FR
├── الكشف: fr (مدعومة)
├── النتيجة: واجهة فرنسية
└── التخزين: fr في localStorage
```

### ملاحظات مهمة

1. **اللغة الافتراضية للزوار الجدد هي الإنجليزية** (وليس العربية) لأن الزوار قد يكونون من أي بلد
2. **يتم التخزين فوراً** عند أول زيارة لتجربة مستخدم سلسة
3. **المستخدم يستطيع التغيير في أي وقت** من إعدادات الحساب
4. **عند تسجيل الدخول** يتم استخدام `ui_language` من الحساب بدلاً من الكشف التلقائي

#### مكون مبدل اللغة

```tsx
// components/LanguageSwitcher.tsx
'use client';

import { useLocale } from 'next-intl';
import { useRouter, usePathname } from 'next/navigation';
import { localeNames, locales, rtlLocales } from '@/i18n/config';

export function LanguageSwitcher() {
  const locale = useLocale();
  const router = useRouter();
  const pathname = usePathname();

  const switchLanguage = (newLocale: string) => {
    // تغيير اتجاه الصفحة
    document.documentElement.dir = rtlLocales.includes(newLocale as any) ? 'rtl' : 'ltr';
    document.documentElement.lang = newLocale;
    
    // تغيير المسار
    router.push(`/${newLocale}${pathname}`);
  };

  return (
    <select onChange={(e) => switchLanguage(e.target.value)} value={locale}>
      {locales.map((loc) => (
        <option key={loc} value={loc}>
          {localeNames[loc]}
        </option>
      ))}
    </select>
  );
}
```

## ملخص
