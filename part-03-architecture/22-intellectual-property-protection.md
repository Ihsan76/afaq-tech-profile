# توثيق وحماية حقوق الملكية الفكرية والبرمجية لمنصة آفاق (Afaq Tech)

> **تاريخ الإنشاء**: 20 أغسطس 2026
> **الحالة**: موثق ومعتمد 🔒

---

## 1. مقدمة
تعتبر منصة **آفاق (Afaq Tech)** منظومة رقمية متكاملة تتضمن شفرات برمجية (Source Code)، قواعد بيانات معمارية، نماذج ذكاء اصطناعي، ومحتوى تعليمي ومناهج رسمية. لحماية هذه الأصول والمكتسبات، تعتمد المنصة آلية مزدوجة تجمع بين الحماية القانونية الرسمية في المملكة الأردنية الهاشمية والحماية التقنية والهندسية المدمجة في معمارية النظام.

---

## 2. المسار القانوني والإداري (في الأردن)

### أ. دائرة المكتبة الوطنية (National Library Department)
* **توثيق المصنفات البرمجية:**
  * تسجيل الشفرة المصدرية (Source Code) والمستندات التقنية للمنصة لدى دائرة المكتبة الوطنية استناداً إلى **قانون ححق المؤلف** الأردني لحماية الحقوق الأدبية والمادية للمطورين والمنصة.
* **المحتوى الرقمي والمؤلفات:**
  * تسجيل المقالات، المناهج التفاعلية، نواتج التعلم، والكتب الإلكترونية الخاصة بالمنصة.

### ب. وزارة الصناعة والتجارة والتموين (سجل العلامات التجارية)
* **تسجيل العلامة التجارية (Trademark):**
  * تسجيل اسم وشعار المنصة (**آفاق / Afaq Tech**) والهوية البصرية بموجب **قانون العلامات التجارية** ضمن التصنيفات الدولية (Nice Classification):
    * *الفئة 9:* برمجيات الحاسوب، التطبيقات الذكية، والمنصات الرقمية.
    * *الفئة 38:* خدمات الاتصالات وبوابات الإنترنت ونقل البيانات.
    * *الفئة 41:* الخدمات التعليمية، التدريبية، ونشر الدورات والمناهج عبر الإنترنت.

### ج. الكيان القانوني
* تسجيل الشركة الحاضنة للمنصة لدى **مراقبة الشركات (CCD)** بغايات تشمل تطوير البرمجيات والخدمات التعليمية الإلكترونية.

---

## 3. المسار التقني والهندسي (مدمج في المنصة)

### أ. التوثيق التاريخي الرقمي (Cryptographic Proof & Version Control)
* استخدام أنظمة إدارة الإصدارات (Git) مع التوقيعات الرقمية المعتمدة (GPG Signatures) في مستودعات الكود، مما يوفر إثباتاً زمنياً (Timestamping) قاطعاً وغير قابل للتلاعب لتاريخ ابتكار وتطوير كل سطر برمجي ومكون.

### ب. حماية المحتوى الرقمي والملكية (DRM & Access Control)
* **التحكم بالوصول (Access Control):** حماية الدورات، الكتب، والمناهج بروابط آمنة وصلاحيات دقيقة (`access_level` و `is_purchased`) تمنع الوصول غير المصرح به.
* **تأمين التنزيلات:** حماية المرفقات والملفات عبر ترويسات استجابة أمنية (`Content-Disposition: attachment`) وحظر الوصول المباشر للملفات الحساسة.

### ج. أمان الشفرة والبنية التحتية
* **فحوصات الأمان التلقائية (CI Security Pipelines):** تنفيذ أدوات الفحص مثل Gitleaks و Bandit و Dependency Audits ضمن خط أنابيب البناء (CI/CD) لمنع تسريب المفاتيح أو الثغرات.
* **تشفير قواعد البيانات وحماية البيانات الشخصية:** استخدام Supabase مع أمان مستويات الصفوف (RLS - Row Level Security) وتشفير البيانات أثناء النقل والتخزين.

## 4. ملخص الأصول المحمية
| الأصول | طريقة الحماية | الجهة المسؤولة / الآلية التقنية |
|-------|---------------|-------------------------------|
| الشفرة المصدرية (Source Code) | حقوق المؤلف + Git History | دائرة المكتبة الوطنية + GitHub |
| العلامة التجارية (Afaq Tech) | علامة تجارية مسجلة | وزارة الصناعة والتجارة (CCD) |
| قواعد البيانات والهيكلة | توثيق هندسي وقانوني | وثائق المعمارية + المكتبة الوطنية |
| المحتوى التعليمي والكتب والدورات | حماية وصول رقمي (DRM) + تشفير | صلاحيات النظام (`access_level`) |
