# تقييم جاهزية منصة آفاق لمتطلبات الامتثال التنظيمي وحماية الملكية الفكرية

> **تاريخ الإنشاء**: 20 أغسطس 2026
> **الحالة**: موثق ومعتمد 📋

---

## 1. مقدمة
يقدم هذا المستند تقييماً تفصيلياً لمدى جاهزية منصة **آفاق (Afaq Tech)** لتنفيذ المتطلبات الواردة في دليلي الامتثال التنظيمي في الأردن (`21-regulatory-compliance-jordan.md`) وحماية الملكية الفكرية (`22-intellectual-property-protection.md`).

---

## 2. تقييم الامتثال التنظيمي والتشريعي في الأردن

| الجهة التنظيمية / التشريع | المتطلب الرئيسي | مدى الالتزام والجاهزية في المنصة |
|--------------------------|-----------------|-----------------------------------|
| **وزارة الاقتصاد الرقمي والريادة (MODEE)** | قانون حماية البيانات الشخصية رقم 24 لسنة 2023 (موافقات Consent، تشفير، حق الحذف والتصدير) | **ممتاز (مفعل بالكامل)** عبر وحدة `gdpr_models.py` وتشفير Supabase ونظام الأدوار RBAC. |
| **وزارة الاقتصاد الرقمي والريادة (MODEE)** | قانون المعاملات الإلكترونية (الشروط، الأحكام، العقود الرقمية) | **مفعل** عبر نظام إدارة الصفحات والبلوكات (`apps/pages`) وشروط الاستخدام. |
| **وزارة التربية والتعليم (MoE)** | مواءمة المناهج الرسمية وحقوق الملكية التعليمية (Curriculum Injection) | **مفعل** عبر زرع المناهج الرسمية مع نواتج التعلم (46 وحدة معتمدة). |
| **البنك المركزي الأردني (CBJ)** | بوابات الدفع الإلكتروني المرخصة ومعايير أمن المدفوعات (PCI-DSS) | **مفعل** عبر دمج بوابة MyFatoorah والتحقق من الويب هوك (HMAC Signature). |
| **وزارة الصناعة والتجارة (CCD)** | التأسيس والترخيص التجاري للأنشطة التقنية والتعليمية | **جاهز إدارياً وقانونياً** للتسجيل الرسمي. |
| **هيئة تنظيم قطاع الاتصالات (TRC)** | أمان البنية التحتية واستقرار الخدمات الرقمية وبث المحتوى | **مفعل** عبر استضافة سحابية مستقرة ومراقبة حية عبر Sentry و CI/CD. |

## 3. تقييم جاهزية حماية الملكية الفكرية والبرمجية

| الأصل التقني / القانوني | الآلية المعتمدة | تقييم الجاهزية |
|--------------------------|------------------|-----------------|
| **الشفرة المصدرية (Source Code)** | التوثيق التاريخي عبر Git History والتوقيعات الرقمية + تسجيل المكتبة الوطنية | **جاهز بنسبة 100%** (سجل تاريخي كامل وموثق). |
| **العلامة التجارية (Afaq Tech)** | تسجيل العلامة التجارية ضمن الفئات الدولية (9, 38, 41) لدى سجل العلامات التجارية | **جاهز للإيداع الرسمي**. |
| **المحتوى المدفوع (الدورات والكتب)** | التحكم بالوصول الرقمي (`access_level` و `is_purchased`) وبوابات الدفع الموحدة | **جاهز ومُفعّل بالكامل**. |
| **المرفقات والملفات الحساسة** | تأمين التنزيلات عبر ترويسات HTTP آمنة (`Content-Disposition: attachment`) | **مفعل بالكامل**. |
| **أمان الشفرة ومنع تسريب الأسرار** | فحص تلقائي عبر خطوط بناء CI (Gitleaks, Bandit, Dependency Audits) | **مفعل بالكامل**. |
