# شاشات المصادقة

## شاشة تسجيل الدخول

### العناصر
- حقل البريد الإلكتروني (إلزامي)
- حقل كلمة المرور (إلزامي)
- زر "تسجيل الدخول"
- رابط "نسيت كلمة المرور؟"
- رابط "ليس لديك حساب؟ سجّل الآن"
- زر تسجيل الدخول بـ Google (مستقبلاً)

### السلوك
- التحقق من صحة البيانات قبل الإرسال
- عرض رسالة خطأ واضحة عند فشل تسجيل الدخول
- إعادة توجيه حسب الدور:
  - معلم → `/teacher`
  - طالب → `/student`
  - مدير → `/admin`
- حفظ JWT في HttpOnly cookie
- تقييد محاولات الدخول (5 محاولات / 30 دقيقة)

---

## شاشة التسجيل

### العناصر
- حقل الاسم الكامل (إلزامي)
- حقل البريد الإلكتروني (إلزامي)
- حقل كلمة المرور (إلزامي، 8+ أحرف)
- حقل تأكيد كلمة المرور (إلزامي)
- اختيار الدور:
  - معلم
  - طالب
- خانة الموافقة على الشروط (إلزامي)
- زر "إنشاء حساب"
- رابط "لديك حساب؟ سجّل دخولك"

### السلوك
- التحقق من تطابق كلمتي المرور
- التحقق من قوة كلمة المرور (12+ حرف، أرقام، رموز)
- إرسال بريد التحقق بعد التسجيل
- إعادة توجيه إلى صفحة التحقق

---

## شاشة التحقق من البريد

### العناصر
- أيقونة تحقق كبيرة
- عنوان: "تحقق من بريدك الإلكتروني"
- رسالة: "أرسلنا رابط التحقق إلى {email}"
- زر "إعادة الإرسال"
- زر "فتح البريد الإلكتروني"

### السلوك
- التحقق من الرابط في البريد
- تفعيل الحساب بعد التحقق
- إعادة توجيه إلى تسجيل الدخول

---

## شاشة إعادة تعيين كلمة المرور

### العناصر (خطوة 1)
- حقل البريد الإلكتروني
- زر "إرسال رابط إعادة التعيين"

### العناصر (خطوة 2)
- حقل كلمة المرور الجديدة
- حقل تأكيد كلمة المرور
- زر "تحديث كلمة المرور"

### السلوك
- إرسال رابط إعادة التعيين عبر البريد
- صلاحية الرابط: 24 ساعة
- إعادة توجيه إلى تسجيل الدخول بعد التحديث

---

## تدفقات المصادقة

```
المستخدم → تسجيل الدخول → Backend → JWT → Frontend → Cookie
    │
    ├── نسيت كلمة المرور → Backend → بريد إعادة التعيين → صفحة جديدة → تحديث
    │
    ├── التسجيل → Backend → بريد التحقق → تفعيل → تسجيل الدخول
    │
    └── Google (مستقبلاً) → OAuth → Backend → JWT → Frontend
```
