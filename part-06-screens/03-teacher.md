## شاشة لوحة المعلم (Dashboard)

### العناصر المُنفّذة ✅
- **بطاقة النقاط والشارات**: تعرض `points` + `badges` مع ألوان متدرجة
- **إحصائيات سريعة (5 بطاقات)**:
  - إجمالي الخطط
  - الخطط المنشورة

  - إجمالي الاستنساخات
  - إجمالي التحميلات
- **روابط سريعة**:
  - "إنشاء خطة جديدة" → `/lesson-plans/new`

### هيكل الصفحة

```

## شاشة عرض خطة الدرس — مُنفّذة ✅

### العناصر
- **Header**: عنوان الخطة
- **المحتوى المقروء**:
  - الأهداف التعليمية (objectives)
  - المواد والوسائل (materials_needed)
  - المقدمة والتمهيد (introduction)
  - الأنشطة الرئيسية (main_activity مع خطوات)
  - التقييم (assessment)
  - الواجب (homework)
  - المدة والوسائل التعليمية
  - **ورقة العمل** (worksheet) — إن وُجدت
  - **الواجب المنزلي** (homework_assignment) — إن وُجد

### أزرار الإجراءات (أسفل الخطة)
| الزر | الوظيفة | الحالة |
|------|---------|--------|
| 📋 نسخ الخطة | duplicate | ✅ |
| 💬 تعديل بالذكاء الاصطناعي | refine (مودال) | ✅ |
| 📄 ورقة عمل | توليد ورقة عمل | ✅ |
| 📝 واجب منزلي | توليد واجب | ✅ |
| 🌍 مشاركة في السوق | toggle-public | ✅ |
| 🗑️ حذف | delete (مع تأكيد) | ✅ |
| 🖨️ طباعة | طباعة (بدون footer) | ✅ |

### السلوك
- عرض RTL كامل
- FadeIn animation عند التحميل
- زر "مناقشة مع AI" يفتح مودال للمحادثة
- زر "حذف" مع مربع تأكيد
- زر "مشاركة" يغيّر حالة `is_public`
- **الطباعة**: تُخفى الـ nav و footer و chat widget تلقائياً (`@media print`)
- **طباعة ورقة العمل**: نافذة جديدة مع `page-break-inside: avoid`

## تدفق عمل المعلم — مُنفّذ ✅

```
المعلم → تسجيل الدخول → Dashboard (إحصائيات + روابط)
                            │
            ┌───────────────┼───────────────┐
            ▼               ▼               ▼
      إنشاء خطة درس   قائمة الخطط      سوق الخطط
            │               │               │
            ▼               ▼               ▼
      توليد AI → عرض    عرض/تعديل/     تصفّح/إعجاب/
      → تعديل (refine)  حذف/طباعة      استنساخ
      → ورقة عمل
      → واجب منزلي
      → مشاركة (toggle-public)
```
المعلم → اختيار المناهج → إدخال التفاصيل → توليد AI → مراجعة → تعديل → تصدير/مشاركة
```
