# شاشات الطالب

## شاشة لوحة الطالب

### العناصر
- **إحصائيات سريعة**:
  - الدورات المسجلة
  - ساعات الدراسة
  - التقدم الإجمالي
  - المهام المعلقة
- **آخر النشاطات**: آخر الدورات أو الاختبارات
- **تذكيرات**: مواعيد التسليم
- **توصيات AI**: دورات أو محتوى مقترح

---

## شاشة الدورات المسجلة

### العناصر
- **قائمة الدورات**: بطاقات لكل دورة
  - صورة الدورة
  - عنوان الدورة
  - المدرب
  - شريط التقدم (0-100%)
  - عدد الدروس المتبقية
- **الفلاتر**: النشطة، المكتملة، المعلقة

### السلوك
- النقر على الدورة → شاشة تفاصيل الدورة
- تحديث التقدم تلقائياً
- عرض شهادة عند اكتمال الدورة

---

## شاشة تفاصيل الدورة

### العناصر
- **Header**: صورة + عنوان + مدرب + تقييم
- **التنقل**: فصول / دروس
- **شريط التقدم**: نسبة الإكمال
- **قائمة الدروس**:
  - عنوان الدرس
  - النوع (فيديو/نص/اختبار)
  - المدة
  - الحالة (مكتمل/غير مكتمل/قفل)
- **زر المتابعة**: ".continue من حيث توقفت"

---

## شاشة عرض الدرس

### العناصر
- **مشغل الفيديو**: إذا كان الدرس فيديو
- **محتوى النص**: إذا كان الدرس نصياً
- **الموارد**: ملفات مرفقة
- **ملاحظات الطالب**: حقل لكتابة ملاحظات
- **إكمال الدرس**: زر "تم الانتهاء"
- **الدرس التالي/السابق**

### السلوك
- تتبع وقت المشاهدة
- حفظ مكان التوقف (Resume)
- تحديث التقدم بعد إكمال الدرس
- عرض اختبار بعد الفيديو (إذا كان مطلوباً)

---

## شاشة المساعد الذكي (Chat)

### العناصر
- **شريط المحادثة**: رسائل المستخدم + ردود AI
- **حقل الإدخال**: كتابة السؤال
- **أزرار مقترحة**: أسئلة شائعة
- **إعدادات المحادثة**: اللغة، الموضوع

### السلوك
- إرسال السؤال → توليد رد AI
- عرض مؤشر الكتابة أثناء الانتظار
- حفظ تاريخ المحادثة
- دعم Markdown في الردود
- إمكانية تقييم الرد (👍/👎)

---

## شاشة الاختبارات

### العناصر
- **قائمة الاختبارات**: المتاحة والمكتملة
- **شاشة الاختبار**:
  - السؤال الحالي
  - الخيارات
  - ترقيم الأسئلة
  - المؤقت (إذا كان محدداً)
  - زر التالي/السابق
- **النتائج**: درجة + تفاصيل الإجابات

---

## شاشة التقدم

### العناصر
- **رسم بياني**: التقدم عبر الزمن
- **إحصائيات**: ساعات الدراسة، الدورات المكتملة
- **الإنجازات**: شارات (badges)
- **المقارنة**: مع المتوسط العام (اختياري)

---

## تدفق عمل الطالب

```
الطالب → تسجيل الدخول → استعراض الدورات → التسجيل → مشاهدة الدروس → اختبار → شهادة
         │
         └── المساعد الذكي → سؤال → رد AI → تقييم
```
