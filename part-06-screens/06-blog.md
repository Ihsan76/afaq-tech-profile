# شاشات المدوّنة — الحالة الفعلية

> **حالة التنفيذ:** مكتمل ✅

---

## شاشة قائمة المقالات (العام) ✅

**المسار**: `/[locale]/blog`

### العناصر
- **Header**: "المدوّنة" / "Blog" مع إحصائية عدد المقالات
- **فلاتر التصنيف**: أزرار للتصنيفات (All, Platform News, Tutorials, AI & Education, Digital Marketing, Web Development)
- **شريط بحث**: بحث بالعنوان (عربي/إنجليزي)
- **بطاقات المقالات**: شبكة 3 أعمدة — كل بطاقة فيها:
  - صورة مميزة (أو placeholder)
  - تصنيف + badge مميز (إذا كان مميزاً)
  - العنوان (عربي أو إنجليزي حسب اللغة)
  - المقتطف
  - الكاتب + صورة + وقت القراءة
  - تاريخ النشر (تنسيق منسق)
- ** Pagination**: التنقل بين الصفحات (10 مقالات/صفحة)

### الملف: `app/[locale]/blog/page.tsx`

## شاشة تفاصيل المقال ✅

**المسار**: `/[locale]/blog/[slug]`

### العناصر
- **رجوع**: زر "← العودة للمدوّنة"
- **العنوان الرئيسي** (عربي أو إنجليزي)
- **معلومات المقال**: تصنيف + تاريخ + وقت القراءة + مشاهدات
- **المحتوى**: HTML مُنسّق (H2, H3, قوائم, صور, روابط)
- **أزرار المشاركة**: Twitter, Facebook, WhatsApp, نسخ الرابط
- **مقالات ذات صلة**: (مُخطط)
- **قسم التعليقات**: (مُخطط)

### الملف: `app/[locale]/blog/[slug]/page.tsx`

## شاشة إدارة المقالات (الفرونت) ✅

**المسار**: `/[locale]/admin/blog`

### العناصر
- **Header**: "المدوّنة (عدد)" + زر "+ مقال جديد"
- **جدول المقالات**: العنوان EN/AR, التصنيف, وقت القراءة, مشاهدات, تاريخ النشر, إجراءات (تعديل/حذف)
- **نموذج إنشاء/تعديل**:
  - حقول العنوان (EN/AR) + Slug (يُولّد تلقائياً)
  - التصنيف (dropdown)
  - المقتطفات (EN/AR) — textarea
  - **المحتوى (EN/AR)** — **RichTextEditor** (TipTap) مع شريط أدوات:
    - عريض/مائل/تحته خط/يتوسطه خط
    - عناوين H1-H3
    - قوائم نقطية/مرقمة
    - اقتباس
    - محاذاة نص (يسار/وسط/يمين)
    - رابط + صورة
    - تراجع/إعادة
  - الوسوم + وقت القراءة + الكاتب (EN/AR)
  - رابط الخدمة المرتبطة
  - تفعيل مميز
- **أزرار الأسفل**: 💾 حفظ/نشر + 🗑️ حذف (فقط عند التعديل)

### الملف: `app/[locale]/admin/blog/page.tsx`

## شاشة إدارة المقالات (Django Admin — الباك إند) ✅

**المسار**: `http://localhost:8003/admin/blog/blogpost/{id}/change/`

### العناصر
- نموذج Django admin القياسي
- **زر "← Back"** في أسفل الصفحة بجانب أزرار الحفظ (مخصص عبر `templates/admin/submit_line.html`)
- حقول ثنائية اللغة كاملة
- حقل `content_en` / `content_ar` مع textarea (يدعم HTML من RichTextEditor)

### الملفات:
- `backend/apps/blog/admin.py` — تسجيل BlogCategory + BlogPost
- `backend/templates/admin/submit_line.html` — زر الرجوع المخصص
