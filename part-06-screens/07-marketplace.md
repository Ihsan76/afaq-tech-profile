# شاشات السوق — مُنفّذة جزئياً

## السوق المجتمعي لخطط الدروس (مُنفّذ ✅)

> **النطاق الحالي:** مشاركة واستنساخ خطط الدروس فقط. لا يشمل خدمات مدفوعة أو مزودين بعد.

### شاشة استعراض الخطط العامة (Marketplace)

**المسار:** `/lesson-plans/marketplace/`

### العناصر المُنفّذة ✅
- **Header**: "السوق — خطط الدروس العامة" مع وصف
- **بطاقات الخطط**:
  - عنوان الخطة
  - اسم المادة (`subject_name`)
  - اسم المرحلة (`grade_name`)
  - اسم المعلم الناشر (`user_name`)
  - عدد الإعجابات (`likes_count`)
  - عدد مرات الاستنساخ (`clones_count`)
  - تاريخ النشر
- **أزرار الإجراءات**:
  - 👍 إعجاب (زيادة `likes_count`)
  - 📋 استنساخ (نسخ الخطة للمستخدم)
  - 👁️ عرض الخطة
- **حركة FadeIn**: 80ms stagger

### الترجمة
- 9 لغات: عناوين وأوصاف وأزرار
- المفاتيح الجديدة: `marketplace`, `marketplaceTitle`, `marketplaceDesc`, `noPublicPlans`, `clone`, `cloneSuccess`, `likes`, `clones`, `byTeacher`, `shareYourPlan`, `shareHint`

---

## ما هو غير مُنفّذ ❌ (الخطة المستقبلية)

### خدمات مدفوعة
- Service model: عنوان، وصف، سعر، تصنيف
- مزودون مع لوحة تحكم
- شراء ودفع

### Orders والطلبات
- إنشاء طلب شراء
- حالات الطلب: pending → paid → in_progress → completed
- platform_fee 10%

### التقييمات
- ServiceReview مع تعليقات وردود
- احتساب التقييم الإجمالي

### API المزود
- إضافة/تحديث الخدمات
- لوحة تحكم المزود

## تدفق عمل السوق الحالي

```
المعلم → يفتح خطته → ينقر "مشاركة في السوق" (toggle-public)
                                                ↓
                                    تظهر الخطة في /marketplace/
                                                ↓
                                    معلم آخر → يشاهد → يعجب → يستنسخ
```
