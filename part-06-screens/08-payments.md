# شاشات الدفع

## شاشة المحفظة

### العناصر
- **الرصيد الحالي**:
  - الرصيد بالدولار
  - الرصيد بالدينار الأردني
- **شحن المحفظة**:
  - المبلغ (حقل رقمي)
  - طريقة الدفع
  - زر "شحن"
- **سجل المعاملات**: آخر المعاملات

---

## شاشة الاشتراك

### العناصر
- **الباقة الحالية**: الباقة + تاريخ الانتهاء
- **الباقات المتاحة**:

| الباقة | السعر/شهر | الميزات |
|--------|-----------|---------|
| مجاني | $0 | 50 طلب AI/يوم |
| أساسي | $5 | 100 طلب AI/يوم |
| محترف | $15 | 300 طلب AI/يوم |
| فريق | $50 | غير محدود |

- **الانتقال**: ترقية/تخفيض
- **الفوترة**: تاريخ التجديد، طريقة الدفع

---

## شاشة سجل المعاملات

### العناصر
- **الجدول**:
  - رقم المعاملة
  - النوع (دفعة، استرداد، شحن)
  - المبلغ
  - الحالة
  - التاريخ
- **الفلاتر**: النوع، التاريخ، الحالة
- **التفاصيل**: النقر لعرض التفاصيل
- **التصدير**: تصدير CSV/PDF

---

## شاشة الدفع (Checkout)

### العناصر
- **ملخص الطلب**:
  - الخدمة/الاشتراك
  - السعر
  - الرسوم
  - الإجمالي
- **معلومات الدفع**:
  - بطاقة ائتمان / PayPal / Paymob
  - حقول البطاقة (إذا كان بطاقة)
- **تأكيد الدفع**: زر "ادفع الآن"
- **رسالة النجاح/الفشل**

### السلوك
- معالجة آمنة عبر المزود
- لا نخزّن بيانات البطاقة
- إعادة محاولة عند الفشل
- إرسال إشعار بالنتيجة

---

## تدفق الدفع

```
المستخدم → اختيار خدمة → عرض السعر → الدفع → مزود الدفع → تأكيد → إشعار
```
