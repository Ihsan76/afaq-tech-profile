# شاشات الإعدادات

## شاشة الإعدادات العامة

### العناصر
- **الملف الشخصي**:
  - الصورة الشخصية (رفع/تغيير)
  - الاسم الكامل
  - البريد الإلكتروني
  - الهاتف
  - زر "حفظ التغييرات"

- **التفضيلات**:
  - لغة الواجهة (العربية/الإنجليزية/الفرنسية/التركية/الأوردو/الألمانية/الإسبانية/الإندونيسية/البنغالية)
  - لغة المخرجات (المحتوى المولّد بالـ AI)
  - البلد/المنهاج (الأردن/السعودية/مصر/سوريا/...)
  - المنطقة الزمنية
  - التنسيق (الفصل آلاف/فواصل)

- **الأمان**:
  - تغيير كلمة المرور
  - المصادقة الثنائية (مستقبلاً)
  - أجهزة مسجل الدخول
  - حذف الحساب

---

## شاشة الإشعارات

### العناصر
- **الإعدادات**:
  - تفعيل/تعطيل الإشعارات البريدية
  - تفعيل/تعطيل الإشعارات الفورية
  - أوقات الصمت
- **حسب النوع**:
  - إشعارات الدورات
  - إشعارات الدفع
  - إشعارات AI
  - إشعارات المدوّنة
  - إشعارات السوق

---

## شاشة الفوترة

### العناصر
- **معلومات الفوترة**:
  - اسم الشركة/الشخص
  - العنوان
  - رقم الضريبة (إن وجد)
- **طرق الدفع المحفوظة**: بطاقات
- **الفواتير**: سجل الفواتير + تحميل PDF

---

## شاشة حذف الحساب

### العناصر
- تحذير: "هل أنت متأكد من حذف حسابك؟"
- عرض ما سيُحذف:
  - جميع خطط الدروس
  - جميع الدورات المسجلة
  - المحفظة والمدفوعات
- حقل: اكتب "حذف" للتأكيد
- زر "حذف الحساب نهائياً"

---

## تدفق الإعدادات

```
المستخدم → الإعدادات → تعديل البيانات → حفظ → تحديث فوري
         → الأمان → تغيير كلمة المرور → تأكيد عبر البريد
         → حذف الحساب → تأكيد → حذف نهائي
```
