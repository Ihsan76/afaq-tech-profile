## نموذج الدفع

### للمشتري (B2C)
```
المشتري → اختيار خدمة/اشتراك → الدفع → مزود الدفع → تأكيد → خدمة
```

### للمزود (B2B)
```
المزود → بيع خدمة → استلام المبلغ - الرسوم → سحب الأرباح
```

## الباقات

### مجاني (Free)
- 50 طلب AI يومياً
- خطة درس واحدة يومياً
- لا يُسمح بالبيع في السوق
- بدون شهادة

### أساسي (Basic) - $5/شهر
- 100 طلب AI يومياً
- خطط دروس غير محدودة
- تصدير PDF
- بيع في السوق (حد 5 خدمات)

### محترف (Pro) - $15/شهر
- 300 طلب AI يومياً
- كل ميزات الأساسي
- بيع غير محدود
- أولوية في الدعم
- شهادة إتمام مخصصة

### فريق (Team) - $50/شهر
- طلبات AI غير محدودة
- كل ميزات المحترف
- حسابات فريق (حتى 10)
- API access
- دعم مخصص

## تدفقات الدفع

### شحن المحفظة
```
المستخدم → إدخال المبلغ → اختيار طريقة الدفع → الدفع → تأكيد → تحديث الرصيد
```

### الاشتراك
```
المستخدم → اختيار الباقة → الدفع → تأكيد → تفعيل الباقة → إشعار
```

### شراء خدمة
```
المشتري → اختيار خدمة → تأكيد الطلب → الدفع → تنفيذ الخدمة → تقييم → صرف للمزود
```
