# شاشات تطبيق الموبايل

## الشاشات الأساسية

### شاشة تسجيل الدخول
- حقل البريد الإلكتروني
- حقل كلمة المرور
- زر "تسجيل الدخول"
- رابط "نسيت كلمة المرور؟"
- رابط "ليس لديك حساب؟"

### شاشة التسجيل
- حقل الاسم
- حقل البريد الإلكتروني
- حقل كلمة المرور
- حقل تأكيد كلمة المرور
- اختيار الدور (معلم/طالب)
- زر "إنشاء حساب"

---

## شاشات المعلم

### لوحة المعلم (Home)
- إحصائيات سريعة (عدد الخطط، AI)
- آخر الخطط
- زر "إنشاء خطة جديدة"

### إنشاء خطة درس
- اختيار المادة
- اختيار المرحلة
- إدخال الموضوع
- إدخال المدة
- زر "توليد"

### تفاصيل الخطة
- عنوان الخطة
- الأهداف
- المدة
- المواد
- النشاط التمهيدي
- النشاط الرئيسي
- التقييم
- الواجب
- أزرار: تعديل، تصدير، مشاركة

### قائمة الخطط
- بحث
- فلتر (المادة، المرحلة)
- قائمة الخطط (بطاقات)

---

## شاشات الطالب

### لوحة الطالب (Home)
- إحصائيات (دورات، ساعات دراسة)
- آخر النشاطات
- توصيات

### المساعد الذكي
- شريط المحادثة
- حقل الإدخال
- أزرار مقترحة

### الدورات
- قائمة الدورات المسجلة
- شريط التقدم
- عدد الدروس المتبقية

### تفاصيل الدورة
- صورة الدورة
- العنوان
- المدرب
- قائمة الفصول والدروس
- زر "متابعة"

### عرض الدرس
- مشغل الفيديو / محتوى نصي
- الموارد
- ملاحظاتي
- إكمال الدرس

---

## شاشة الإعدادات

- الملف الشخصي (اسم، صورة، بريد)
- تغيير كلمة المرور
- إعدادات الإشعارات
- اللغة
- تسجيل الخروج
- حذف الحساب

## شاشة الإشعارات

- قائمة الإشعارات
- تحديد كمقروء
- حذف

## التنقل

```
Bottom Tabs:
├── الرئيسية (Home)
├── خططي (My Plans) - للمعلم
├── الدورات (Courses) - للطالب
├── المساعد (Assistant)
└── المزيد (More) → Profile, Settings, etc.
```

---

## تدفقات العمل

### تدفق المعلم
```
فتح التطبيق → لوحة المعلم → إنشاء خطة → توليد AI → مراجعة → تعديل → حفظ/مشاركة
```

### تدفق الطالب
```
فتح التطبيق → لوحة الطالب → اختيار دورة → مشاهدة درس → اختبار → تقدم
         └── المساعد الذكي → سؤال → رد AI
```
