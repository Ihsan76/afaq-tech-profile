## إدارة المدوّنة

### أدوات الكتابة
- **المحرر**: Rich Text Editor (TipTap) — مدمج في BlockEditorPanel و Blog admin
- **الدعم**: تنسيق نصي كامل (عريض، مائل، عناوين، قوائم، اقتباس، صور، روابط)
- **ثنائي اللغة**: محتوى EN/AR منفصل مع محرر منفصل لكل لغة
- **المسودات**: حفظ عبر `is_published` flag

### تدفق العمل
```
مدير → إنشاء مقال → كتابة المحتوى (RichTextEditor) → حفظ/نشر → ظهور في الموقع
```

### APIs
```
GET  /api/v1/blog/posts/              — المقالات المنشورة (AllowAny)
GET  /api/v1/blog/posts/{slug}/       — تفاصيل مقال (AllowAny)
GET  /api/v1/blog/categories/         — التصنيفات (AllowAny)
GET  /api/v1/blog/admin/posts/        — جميع المقالات (IsAdminUser)
POST /api/v1/blog/admin/posts/create/ — إنشاء مقال (IsAdminUser)
PUT  /api/v1/blog/admin/posts/{id}/   — تعديل مقال (IsAdminUser)
DELETE /api/v1/blog/admin/posts/{id}/ — حذف مقال (IsAdminUser)
```

### الأدوار الوصول
| الدور | الصلاحيات |
|-------|-----------|
| زائر | قراءة المقالات المنشورة |
| مدير | إنشاء، تعديل، حذف، نشر أي مقال |

    DEFAULT_META_TITLE = 'آفاق تكنولوجي - منصة التعليم الذكي'
