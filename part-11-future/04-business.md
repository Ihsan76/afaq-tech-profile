# نموذج الأعمال

## مصادر الإيرادات

### 1. الاشتراكات (Primary)
```
مجاني: $0/شهر → تحويل مجاني
أساسي: $5/شهر → 500 طالب مستهدف
محترف: $15/شهر → 200 معلم مستهدف
فريق: $50/شهر → 50 مؤسسة مستهدفة

الإيرادات المتوقعة (السنة الأولى): $1,000-5,000/شهر
```

### 2. سوق الخدمات
```
رسوم المنصة: 10% من كل صفقة
الخدمات: خطط دروس، دورات، استشارات

الإيرادات المتوقعة (السنة الأولى): $500-2,000/شهر
```

### 3. B2B (المستقبل)
```
اشتراكات المؤسسات
تخصيص المنصة
تدريب ودعم

الإيرادات المتوقعة (السنة 3+): $10,000+/شهر
```

## مصادر التمويل

### خيارات التمويل
1. **Bootstrapping**: تمويل ذاتي
2. **Angel Investment**: مستثمرون ملاك
3. **Venture Capital**: رأس مال مغامرة
4. **Grants**: منح حكومية/دولية
5. **Crowdfunding**: تمويل جماعي

### التوصية
```
السنة الأولى: Bootstrapping
السنة الثانية: Angel Investment
السنة الثالثة: VC (اختياري)
```

## مؤشرات الأداء (KPIs)

### المستخدمون
- عدد المستخدمين المسجلين
- المستخدمون النشطون يومياً/شهرياً
- معدل الاحتفاظ (Retention)

### الإيرادات
- الإيرادات الشهرية المتكررة (MRR)
- قيمة العميل مدى الحياة (LAV)
- تكلفة اكتساب العميل (CAC)

### المنتج
- معدل التحويل (مجاني → مدفوع)
- استخدام AI (طلبات/يوم)
- تقييم المستخدمين
