## الأثر الفعلي (أغسطس 2026)

- **المنصة حية**: `afaq.app` (Vercel) + `api.afaq.app` (Render) خلف Cloudflare.
- **الأداء**: menu 2.5s ← 0.4s، ترجمات 561KB ← 56KB، إزالة +2s لكل endpoint (Redis محجوب إقليمياً).
- **المراقبة**: مراقب خارجي 24/7 على health endpoint + Sentry + طلبات رفع Safe Browsing flag مقدمة.
- **الاختبارات**: 90 pytest ناجحة + ruff نظيف + CI أخضر + tsc نظيف.
- **المدارس SIS**: نماذج 15+ موديل + APIs مكتملة + واجهات 4 أدوار + FAQ Copilot + دورة عام دراسي + تصدير PDF/Excel + إشعارات واتساب.
- **RBAC الشامل (أغسطس 2026)**: نظام أدوار موحد عبر `UserRole` (FK) بدلاً من `User.role` القديم؛ `RoleService` موحّد للتحقق والتعيين والإزالة؛ `RoleRequest` للمستخدمين لطلب أدوار (instructor/publisher/service_provider)؛ `SchoolStaff` لإدارة طاقم المدرسة؛ `SchoolManagerRequest` لنقل ملكية المدارس؛ تدفق تسجيل مُبسّط (ادخار student/parent مع تأكيد البريد)؛ CI مُصحّح بالكامل (51+ ruff error + fixtures + middleware + bandit).
