# نظام التتبع الذكي وإدارة الأجهزة (Smart Tracking & Device Management)

> **تاريخ الإنشاء:** 20 أغسطس 2026
> **الحالة:** مكتمل ✅

---

## 1. ملخص المشروع
بناء نظام متكامل يدعم إدارة الأجهزة الذكية (أجهزة GPS، قارئات RFID، كاميرات التعرف على الوجه، هواتف السائقين) وربطها بمنصة آفاق لتفعيل التتبع الحي للحافلات وتسجيل الحضور والغياب آلياً.

---

## 2. المكونات البرمجية

### أ. نماذج قاعدة البيانات (Backend Models)
- **`SchoolDevice`**: إدارة جميع الأجهزة المرتبطة بالمدرسة (نوع الجهاز، المعرف الفريد، الحالة، الجهاز المخصص).
- **`BusLocationLog`**: سجل إحداثيات الحافلات اللحظية (خط العرض، خط الطول، السرعة، الوقت).
- **`DeviceEvent`**: سجل أحداث الأجهزة (عمليات مسح البطاقات، تسجيلات كاميرات الوجه).
- **`BusStop`**: محطات ونقاط التجمع لخطوط سير الحافلات (اسم المحطة، الإحداثيات، الترتيب، الحالة).

### ب. نقاط النهاية البرمجية (API Endpoints)
| المسار | الوصف |
|---|---|
| `GET/POST /api/v1/schools/devices/` | إدارة أجهزة المدرسة (إضافة / عرض / تعديل) |
| `DELETE /api/v1/schools/devices/<id>/` | حذف / تعطيل جهاز |
| `POST /api/v1/schools/devices/<id>/regenerate-token/` | إعادة توليد مفتاح الأمان للجهاز |
| `POST /api/v1/schools/telemetry/` | استقبال إحداثيات GPS من الهواتف / أجهزة التتبع |
| `POST /api/v1/schools/scan/` | استقبال عمليات مسح بطاقات RFID / كاميرات الوجه |
| `GET /api/v1/schools/buses/<id>/location/` | جلب آخر موقع معروف لحافلة |
| `GET /api/v1/schools/buses/live/` | جميع مواقع الحافلات النشطة لحظياً |
| `GET/POST /api/v1/schools/bus-stops/` | إدارة محطات خطوط السير (إضافة / عرض / تعديل / حذف) |

### ج. شاشات الفرونتايند (Frontend Pages)
- **إدارة الأجهزة** (`/school/admin/devices`): جدول عرض الأجهزة، إضافة/تعديل/حذف، توليد التوكن.
- **واجهة السائق** (`/school/driver`): واجهة موبايل لبدء الرحلة وبث الموقع ومسح بطاقات الطلاب.
- **خريطة التتبع الحي** (`/school/transport/map`): خريطة تفاعلية لحظية لمواقع الحافلات.
- **إدارة النقل المدرسي** (`/school/transport`): CRUD كامل للحافلات، خطوط السير، المحطات، وتخصيص الطلاب (أغسطس 2026).

---

## 3. دعم الهواتف الذكية كبديل لأجهزة GPS
- يمكن استخدام هاتف السائق كجهاز تتبع GPS عبر تطبيق محمول أو PWA.
- يرسل التطبيق إحداثيات الموقع (`latitude`, `longitude`, `speed`) كل 10 ثوانٍ عبر `POST /api/v1/schools/telemetry/`.
- يدعم الهاتف ALSO قراءة بطاقات RFID عبر:
  - **NFC مدمج:** إذا كانت البطاقات تدعم NFC.
  - **قارئ RFID خارجي:** ربط قارئ Bluetooth صغير بالهاتف.
